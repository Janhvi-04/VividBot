VividBot is an interactive web platform designed to build daily habits through structured AI micro-modules, including logic puzzles, coding challenges, curiosity quests, and mindfulness tasks.

Key Features

* Dynamic AI Content: Generates real-time educational prompts, hints, and mindfulness exercises using an integrated backend.
* Smart Daily Limits: Enforces daily usage constraints to encourage consistent habits rather than binge usage.
* Global Error Handling: Uses a custom `apiFetch` wrapper to catch limit restrictions and display custom toast notifications.
* Immersive Experience: Features smooth typewriter text streaming, custom themes, and fully responsive layouts built with React, Node.js, Express, and MongoDB.
